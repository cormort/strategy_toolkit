MOD-01 商務談判 // 社交博弈

極端戰略沉默協議

底層認知漏洞

大腦對社交空白具有強烈的生理恐懼與填補衝動，往往會自亂陣腳主動讓步。

觸發情境

報出極端高價錨點後、向對方提出重大要求後、或對話陷入僵局時。

最小物理動作
完成報價後：立刻咬緊舌頭，強制閉嘴 30 秒。
致命禁忌
嚴禁在對方開口前回應或主動補充藉口／打折。

MOD-02 決策止損 // 戰略重構

空降旁觀者置換協議

底層認知漏洞

沉沒成本謬誤與稟賦效應：對過往付出難以割捨，導致持續加碼維持虧損行為。

觸發情境

專案持續虧損但捨不得收手、不良合作關係糾纏不清、因投入過多而猶豫。

最小物理動作
想像自己被開除，空降的冷血職業經理人第一刀砍什麼，現在就立刻砍什麼。
致命禁忌
嚴禁回顧「已經投入了多少成本」，不要為過去的屍體買單。
葛洛夫置換法則
MOD-03 動量點火 // 跨越靜摩擦力

兩分鐘微重力點火協議

底層認知漏洞

大腦面對龐大任務會產生高靜摩擦阻力，多巴胺系統會誘使身體逃避至低阻力娛樂。

觸發情境

癱坐滑手機明知該工作卻動不了、面對複雜文件不知從何下手、嚴重拖延。

最小物理動作
手機螢幕朝下扣在桌上，坐在鍵盤前敲下 3 個字母或標題，持續 2 分鐘。
致命禁忌
嚴禁在開始前規劃宏大架構或試圖一口氣完成整份工作。
02:00
MOD-04 說服重塑 // 損失框架

損失框架反轉協議

底層認知漏洞

前景理論：人類對「潛在損失」的痛苦感知是「同等獲益」愉悅感的 2 倍以上。

觸發情境

向主管/客戶提案遭遇拖延推託、對方覺得「維持現狀也可以」時。

最小物理動作
將「導入能賺多少」全部改寫為「維持現狀每天白白流失多少真金白銀」。
致命禁忌
嚴禁只描繪美好願景；沒有失去痛苦的刺激，對手大腦不會行動。
康納曼損失矩陣
MOD-05 思維切斷 // 神經重置

十分鐘物理切割協議

底層認知漏洞

大腦 DMN 迴路陷入思維反芻（Rumination），越試圖「想開」大腦空轉耗能越嚴重。

觸發情境

受冒犯氣得發抖、腦海瘋狂重播爭吵畫面、陷入極度內耗或自責。

最小物理動作
強制離開螢幕，雙手投入具體物理活動（洗冷水臉、用力擦桌子）10 分鐘。
致命禁忌
嚴禁坐在原位嘗試「推理化解」或在通訊軟體上敲鍵盤筆戰。
